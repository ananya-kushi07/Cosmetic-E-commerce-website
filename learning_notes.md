Day 1 – Requirement Analysis and Project Planning

Today, I started working on the internship project titled “GlowMart – Multi Vendor E-Commerce Platform.” I carefully analyzed the given problem statement and identified the major modules required for the system, including Customer Module, Vendor Module, Admin Module, Product Management, Authentication, and Order Handling. I also planned the overall workflow of the application and decided to use the MERN stack for development. Basic project structure and folder organization were discussed and finalized for both frontend and backend development.

From today’s work, I understood the importance of proper requirement analysis before starting development. I learned how planning the project architecture and identifying modules early helps reduce confusion during implementation. I also gained better clarity about how real-world e-commerce platforms are structured and how frontend, backend, and database systems interact together in a full-stack application.

Day 2 – Frontend Setup and UI Design

Today, I initialized the React frontend using Vite and started designing the user interface for the e-commerce platform. I created the basic pages such as Home, Login, Register, Products, Vendor Dashboard, and Admin Dashboard. Navigation routing was implemented using React Router, and Tailwind CSS was used for responsive styling. I also created reusable UI components such as Navbar, Product Cards, and Buttons to maintain consistency throughout the application.

From today’s development process, I learned how component-based architecture in React improves code reusability and project organization. I also understood the importance of responsive design and user-friendly interfaces in web applications. Working with Tailwind CSS helped me improve my frontend styling skills and allowed me to create clean layouts quickly and efficiently.

Day 3 – Backend Setup and MongoDB Integration

Today, I started backend development using Node.js and Express.js. I created the Express server, configured middleware such as CORS and JSON parsing, and connected the application to MongoDB Atlas using Mongoose. Basic folder structure for routes, models, and controllers was created. I also implemented environment variable management using dotenv to securely store database credentials and JWT secrets.

From today’s implementation, I learned how backend servers handle requests and communicate with databases in MERN stack applications. I understood the importance of organizing backend files properly for scalability and maintainability. I also gained practical experience in connecting cloud databases and managing secure configurations using environment variables.

Day 4 – Authentication and User Management

Today, I implemented user authentication features including registration and login functionality. Password hashing was implemented using bcryptjs to improve security, and JWT tokens were generated for secure user authentication. Separate roles such as customer and vendor were added to the user model. Authentication APIs were tested successfully using Postman and integrated with the frontend forms.

From today’s work, I learned the importance of authentication and role-based access control in web applications. I gained understanding about how JWT tokens help maintain secure sessions between frontend and backend systems. I also improved my API development and testing skills while working with Express routes and MongoDB user data.

Day 5 – Product Management and API Integration

Today, I developed product management features for the platform. Product schemas and APIs were created to add, fetch, and delete products from the database. Vendor Dashboard functionality was integrated with backend APIs using Axios. Dynamic product rendering was implemented on the frontend using React Hooks and API calls.

From today’s progress, I understood how CRUD operations are implemented in real-world full-stack applications. I learned how frontend and backend systems communicate using REST APIs and how React state management helps display dynamic data efficiently. This task also improved my understanding of MongoDB document handling and asynchronous API integration.

Day 6 – Testing, Debugging, and Final Improvements

Today, I tested all modules including user registration, login, product addition, product display, and dashboard functionality. Several UI alignment issues and API connection problems were identified and fixed. The project structure was cleaned, README documentation was prepared, and GitHub repository updates were completed. Final frontend improvements and responsiveness adjustments were also made before project submission.

From today’s testing and debugging process, I learned the importance of identifying and fixing issues before deployment. I understood how debugging helps improve system reliability and user experience. I also gained experience in organizing project documentation and maintaining proper version control practices using GitHub commits and repository management.
